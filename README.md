# OS Simulator (Android)

Compose app that simulates **iOS**, **watchOS**, **ColorOS 17** and **Tizen TV** with boot animations, lock screens, launchers, apps and transitions.

- iOS / ColorOS glass effects: [Kyant0/AndroidLiquidGlass](https://github.com/Kyant0/AndroidLiquidGlass) (`io.github.kyant0:backdrop`)
- ColorOS widgets: [compose-miuix-ui/miuix](https://github.com/compose-miuix-ui/miuix) (`top.yukonga.miuix.kmp:miuix-ui`)
- Both upstream repos are also cloned under `third_party/` as references.
- Build: GitHub Actions (`.github/workflows/android.yml`) → debug APK artifact, release on `v*` tag.

Unofficial, for demo/learning only. Not affiliated with Apple, OPPO or Samsung.
